# 更新機能追加 - 実装計画

## 概要
元の言語ファイルの更新機能を追加し、新規追加・削除・変更されたキーに自動でタグを付与する機能を実装する。

## 現在の構造分析

### 既存の主要コンポーネント
- **ListStore.ts**: 翻訳データのリスト管理、タグ機能実装済み
- **EditerStore.ts**: 現在編集中のアイテム管理
- **fileop.ts**: ファイル操作、JSON/langファイルの読み書き
- **projectfile.ts**: プロジェクトファイル（.mctp）の管理
- **fileopen.tsx**: ファイル読み込み機能
- **filesave.tsx**: ファイル保存機能

### 既存のタグシステム
- タグ機能は既に実装済み
- ListStore、EditerStore、fileopでタグ管理
- プロジェクトファイルにitemTags保存済み

## 実装要件

### 主要機能
1. **元ファイル更新機能**
   + 翻訳元ファイル（en_us.json等）の再読み込み
   + 既存データとの差分検出
   + 新規・削除・変更キーの識別

2. **自動タグ付与**
   + 新規追加キー: `new` タグ
   + 削除されたキー: `deleted` タグ 
   + 英訳が変更されたキー: `updated` タグ

3. **更新処理フロー**
   + 更新前後の差分表示
   + ユーザー確認ダイアログ
   + 選択的更新オプション

## 実装セクション

### セクション1: 差分検出ロジック
**ファイル**: `src/util/file/updateDiff.ts`
- 新旧データの比較関数
- 変更種別の判定
- 差分結果のデータ構造定義

### セクション2: 更新処理機能
**ファイル**: `src/util/file/fileUpdate.ts`
- 更新処理のメイン関数
- タグ自動付与ロジック
- データマージ処理

### セクション3: UI更新機能
**ファイル**: 
- `src/component/UpdateDialog.tsx` - 更新確認ダイアログ
- `src/util/file/fileopen.tsx` - 更新機能追加

## データ構造

### 差分検出結果
```typescript
interface UpdateDiff {
  added: string[];      // 新規追加キー
  deleted: string[];    // 削除されたキー  
  modified: {           // 変更されたキー
    key: string;
    oldValue: string;
    newValue: string;
  }[];
  unchanged: string[];  // 変更なしキー
}
```

### 更新タグ定義
- `new`: 新規追加されたキー
- `deleted`: 削除されたキー（論理削除として保持）
- `updated`: 英訳が変更されたキー

## 実装順序
1. 差分検出ロジック実装
2. 更新処理機能実装
3. UI更新機能実装
4. 既存ファイル統合とテスト

## 注意点
- 既存のタグシステムとの互換性維持
- プロジェクトファイル形式の後方互換性
- ユーザーが手動で付けたタグの保護
- 削除されたキーの扱い（論理削除）
