# 設定画面統合アップデート

## 変更概要

ユーザーの要求に基づいて、設定画面を統合し、左側にナビゲーションリストを配置した拡張可能な構造に変更しました。

### 🔄 主な変更点

#### 1. 統合された設定画面構造
- **左側ナビゲーション**: カテゴリ別に整理された設定項目リスト
- **右側コンテンツエリア**: 選択された設定項目の詳細画面
- **フルスクリーン表示**: より広いスペースでの快適な設定操作

#### 2. 拡張可能なアーキテクチャ（&C要件）
```typescript
interface SettingItem {
  id: string;
  name: string;
  icon: React.ReactNode;
  description?: string;
  category: 'ai' | 'general' | 'advanced';
}
```

#### 3. カテゴリ別設定項目

##### 🤖 AI機能
- **Gemini AI**: API設定とプロンプト管理

##### ⚙️ 一般設定
- **外観**: テーマとUI設定（ダークモード切り替え）
- **エディター**: エディター設定とカスタマイズ（開発中）
- **言語設定**: 表示言語とローカライゼーション（開発中）

##### 🔧 高度な設定
- **高度な設定**: デバッグとパフォーマンス（開発中）

## 実装詳細

### ナビゲーション構造
```typescript
const groupedItems = {
  ai: settingItems.filter(item => item.category === 'ai'),
  general: settingItems.filter(item => item.category === 'general'),
  advanced: settingItems.filter(item => item.category === 'advanced')
};
```

### レスポンシブデザイン
- **左側サイドバー**: 固定幅（320px）でカテゴリ別ナビゲーション
- **右側コンテンツ**: 可変幅で設定内容表示
- **アニメーション**: smooth transitions between settings

### 拡張性の特徴
1. **モジュラー設計**: 新しい設定項目を簡単に追加可能
2. **カテゴリシステム**: 論理的な設定グループ化
3. **アイコンシステム**: 視覚的に識別しやすいUI
4. **説明文対応**: 各設定項目の詳細説明

1. **設定項目定義の追加**:
```typescript

  description: '設定の説明',
  category: 'general',
  icon: <NewIcon />
};
```

2. **設定コンポーネントの作成**:
```typescript
const NewSettings = () => (

  </div>
```

3. **レンダリング関数への追加**:
