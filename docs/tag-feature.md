# タグ機能の実装

各翻訳アイテムにタグを付け、管理・フィルタリングする機能。

## 概要

この機能により、ユーザーは各翻訳アイテムに任意の数のタグを付与できます。タグはフィルタリング条件として使用でき、特定のタグを持つアイテムのみをリストに表示させることが可能です。タグ情報はプロジェクトファイル（`.mctp`）に保存され、プロジェクトの読み込み・書き出し時に維持されます。

## データ構造の変更

### 1. ストアの更新

-   `src/component/stores/ListStore.ts`
    -   `item`インターフェースに`tags: string[]`を追加。
    -   ストアの状態に`allTags: string[]`（プロジェクト内の全タグリスト）と`tagFilter: string[]`（現在アクティブなフィルター）を追加。
-   `src/component/stores/EditerStore.ts`
    -   `editer`インターフェースに`tags: string[]`を追加し、現在編集中のアイテムのタグを管理。
-   `src/util/file/fileop.ts`
    -   `translateDataType`インターフェースに`itemTags: { [key: string]: string[] } | null`を追加し、プロジェクトファイルから読み込んだタグ情報を一時的に保持。

### 2. プロジェクトファイルの更新

-   `src/util/file/projectfile.ts`
    -   `ProjectFile`インターフェースの`data`オブジェクトに`itemTags?: { [key: string]: string[] }`を追加。これにより、アイテムのキーをキーとし、タグの配列を値とするオブジェクトが保存されます。

## UIの変更点

### 1. エディタ (`src/component/Editer.tsx`)

-   翻訳文編集エリアの下に「タグ」セクションを追加。
-   現在のアイテムに付与されているタグがバッジとして表示され、クリックで削除可能。
-   新しいタグを入力し、Enterキーで追加できる入力フィールドを設置。

### 2. リスト (`src/component/List.tsx`)

-   各リストアイテムに、付与されているタグがバッジとして表示されるよう変更。
-   リストの上部に「タグで絞り込み」セクションを追加。
-   プロジェクト内に存在するすべてのタグがボタンとして表示される。
-   タグボタンをクリックすると、そのタグがフィルター条件に追加/削除され、リストがリアルタイムで更新される。複数のタグを選択した場合はAND条件で絞り込まれる。

## 機能仕様

-   **タグの追加**: エディタの入力フィールドから追加。すでに追加済みのタグは無視される。
-   **タグの削除**: エディタのタグバッジをクリックして削除。
-   **フィルタリング**: リストのタグボタンをクリックしてフィルタリング。
-   **データの永続化**: タグ情報はプロジェクトファイルに保存され、次回起動時にも復元される。

## 将来的な拡張性

-   タグのオートコンプリート機能。
-   タグ自体の管理機能（リネーム、色分けなど）。
-   複数のタグフィルターのOR条件対応。
